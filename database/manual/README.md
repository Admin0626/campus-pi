适用日期：2026-10-23。测试数据使用虚构账号、图片和历史业务状态，覆盖 A–I 九个模块、112 个基线接口及 5 个补充场景。它是**测试输入和预期结果**，不代表 117 项已全部通过。支付、短信、真实微信等未接通能力也列入矩阵，验收时应看到明确的限制或错误，不能看到伪造成功。

逐页操作请先读[校园Π页面测试使用手册](../../docs/verification/校园Π页面测试使用手册.md)：包含每个页面的进入方法、按钮步骤、测试角色、填写示例、预期结果、闭环测试顺序和问题记录模板。上传时可使用[四张测试PNG样例](上传样例/)。本文件主要说明数据安装和初始状态。

## SQL 文件及首次安装

主文件为[校园Π全功能人工测试.sql](校园Π全功能人工测试.sql)，配套[接口人工测试矩阵.json](接口人工测试矩阵.json)。SQL 内包含虚构业务数据、图片二进制、117 条用例、保护条件和 4 条数据断言。SQL不包含应用程序，也不自动修改日常开发库。

这是完整模块的**数据脚本**，数据库结构沿用仓库已有版本。新机器推荐先安装 Python 的 `pymysql`，准备仅保存在 `.local/manual-test/database-private.json` 的连接配置，再运行：

```powershell
python scripts/prepare_manual_test.py --config .local/manual-test/database-private.json
```

配置格式如下；密码替换为该独立 MySQL 实例的实际密码：

```json
{"host":"127.0.0.1","port":33321,"user":"root","password":"替换成本机测试库密码","database":"campus_pi_manual_test"}
```

安装器固定只接受本机 `campus_pi_manual_test`，空库依次装入 `database/schema/01_数据库结构.sql`、`database/transactions/02_核心业务事务.sql`、V001–V008 迁移，再执行主数据脚本，还原 25 张合成 PNG，并生成私有服务配置。已有用户则拒绝导入，不重置库或覆盖图片。连接密码不会写入共享 SQL。此 root 示例只用于独立本机测试，正式环境另行配置权限。

使用数据库工具手动执行时：先创建专用库，执行上述结构/事务/迁移，再以**整段脚本、遇错停止**方式执行主文件；客户端需要支持 `DELIMITER`，不能逐个分号拆分存储过程。MySQL 的[存储过程说明](https://dev.mysql.com/doc/mysql/8.0/en/create-procedure.html)解释了客户端分隔符的用法。SQL 中所有业务写入均限定专用 schema；库已含用户时过程会拒绝写入。DDL 的提交行为不等于种子数据的事务；成功建库后出现错误，应检查报错再继续，不能在正式库试跑。

手动导入仅有数据库数据，图片还需安装器的文件还原步骤；不要把缺少实体文件造成的 404 当成权限逻辑缺陷。推荐使用安装器一次完成。重新生成主 SQL 才需要 `argon2-cffi`：`python scripts/build_manual_test_sql.py`；日常导入不需要该依赖。

## 尚不能以本数据代替的验收

- API004/005（找回/短信）、API050–052（商品交付/收货/支付）仍有外部依赖，预期为明确的未实现响应；API053/099 仅任务零金额分支可用，商品退款分支未接通。可信支付回调也尚未接入。具体以矩阵及当前接口说明为准。
- 真实微信换码、支付、短信、正式扫描、HTTPS、生产迁移和真机链路需要各自真实环境；没有种入微信身份或真实会话 token。
- 原生资料编辑已获准使用 PUT /me 兼容入口，与原 PATCH 共用校验和事务；真实渲染/真机仍需独立验收。
- 信用分、推荐、活动、多媒体帖子、全局搜索、系统设置等尚未定义范围与规则；不能把占位或历史数据记为实现。

## 校验与复测

主 SQL 最后 4 条断言的 `passed` 均应为 1。额外可执行：

```powershell
python scripts/check_manual_test.py --config .local/manual-test/database-private.json
```

校验器验证专用 schema、初始数据、图片 SHA、用例矩阵、重复装载保护，以及 8082 上实际登录、查询和权限。它只创建短期会话，不消费业务夹具；人工操作后初始状态断言可能变化，此时应根据自己的操作记录判断，不能重导覆盖数据。需要从头测试时，另行备份并由负责人选择清理专用库；本工具不自动删除数据库。

如需重启本机测试服务，使用 Java17，先构建前端及后端，再在仓库根目录执行（私有配置需已生成）：

```powershell
java -jar backend/target/campus-pi-server-0.0.1-SNAPSHOT.jar --spring.config.additional-location=file:./.local/manual-test/application-local.yml
```

正式环境仍使用原迁移和最小权限配置，不装入这套测试口令、历史资金或合成扫描记录。
