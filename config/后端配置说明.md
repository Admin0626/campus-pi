# 后端配置说明

更新日期：2026-10-24。配合根目录[启动步骤](../README.md)使用。

## 配置文件与加载方式

共享模板：[local/application-local.example.yml](local/application-local.example.yml)。首次复制到 `.local/local-deploy/application-local.yml` 后填写本机值；启动脚本会通过 `spring.config.additional-location` 加载它。已有私有配置不要重新复制覆盖。

`backend/src/main/resources/application.yml` 提供默认值；根目录 `.env.example` 只是环境变量模板，Spring Boot **不会自动读取 `.env` 文件**。命令行参数优先于配置文件。所有真实密码、密钥、AppID/AppSecret 与本机接口地址保留在忽略目录中。

## 数据库与服务

|配置项|填写说明|
|---|---|
|`server.address`|本机默认 `127.0.0.1`，只接受本机连接|
|`server.port`|默认 `8080`；修改后同步前端代理、小程序接口和文件基础地址|
|`spring.datasource.url`|指向已导入的 MySQL 8 库；模板为 `127.0.0.1:3306/campus_pi_local`|
|`spring.datasource.username`|建议使用专用账号 `campus_pi_app`|
|`spring.datasource.password`|专用数据库账号的密码，和项目管理员密码分开|

启动不自动建表或迁移。首次只导入 `database/init.sql`；已有库备份后只应用尚未执行的 `database/migrations/V*.sql`。`database/schema.sql` 与迁移文件是初始化生成器和 CI 的结构源，不必在首次安装后再导一遍。修改结构源后运行 `python scripts/build_local_init_sql.py` 生成新初始化脚本，并用 `--check` 检查一致性。

模板 URL 的 `allowPublicKeyRetrieval=true&sslMode=DISABLED` 仅用于单机开发连接。正式部署应按数据库服务的证书和 TLS 要求配置。

## 登录、权限与校区

|配置项|填写说明|
|---|---|
|`campus.auth.idempotency-secret`|至少 32 字符的随机值；生成后固定保存，重启保持不变|
|`campus.auth.local-short-password-admin-id`|本文初始化管理员 ID 为 `1`，仅该本地账号允许短测试密码；其他账号不放宽|
|`campus.admin.duties-json`|用户 ID 到敏感管理职责的 JSON；模板给本地 ID 1 分配管理职责，换库或换管理员时核对 ID|
|`campus.verification.allowed-campuses-json`|允许申请认证的校区名单，初始为 `["本地测试校区"]`；申请名称必须完全匹配|

生成随机密钥，将输出写入私有配置；不要写入共享模板或提交信息：

```powershell
$keyBytes = New-Object byte[] 32
$keyGenerator = [System.Security.Cryptography.RandomNumberGenerator]::Create()
$keyGenerator.GetBytes($keyBytes)
$keyGenerator.Dispose()
([System.BitConverter]::ToString($keyBytes)).Replace('-','').ToLowerInvariant()
```

模板职责包含 `ROLES`、`AUDIT`、`VERIFICATION_REVIEW`、`ORDERS`、`REPORTS`、`NOTIFICATION_PUBLISH`。配置职责不能把普通 `USER` 自动变成 `ADMIN`，仍检查数据库角色和对象权限。会话当前保存在页面内存中，浏览器刷新或小程序冷启动后需重新登录。

## 文件上传与扫描

|配置项|填写说明|
|---|---|
|`campus.files.root`|实际可写的绝对目录，例如仓库下 `.local/local-deploy/files` 的绝对路径；不能放进公开静态目录|
|`campus.files.public-base-url`|本机默认 `http://127.0.0.1:8080`；外部部署须使用可信 HTTPS origin，不含路径、查询参数或认证信息|
|`campus.files.scanner-provider`|当前适配 `DEFENDER`|
|`campus.files.scanner-executable`|电脑上实际存在的 `MpCmdRun.exe` 完整路径|

在 Windows 上查找扫描器：

```powershell
Get-ChildItem 'C:\ProgramData\Microsoft\Windows Defender\Platform\*\MpCmdRun.exe' |
    Select-Object -ExpandProperty FullName
```

将实际路径写入私有 YAML，建议使用 `/` 分隔符。未配置扫描器时登录和查询仍可启动，上传会明确失败；不能填假路径或伪造扫描成功。当前未实现 Linux/macOS 扫描器适配。默认单文件上限 10 MB、请求上限 11 MB，具体用途还有类型和内容校验。

## 后台任务与交易

|配置项|本机建议及作用|
|---|---|
|`campus.notifications.worker-enabled`|`true`，驱动站内通知持久投递|
|`campus.notifications.poll-interval-ms`|默认 `2000`|
|`campus.admin-batches.worker-enabled`|`true`，驱动管理批量任务逐条执行|
|`campus.admin-batches.poll-interval-ms`|默认 `1000`|
|`campus.tasks.synthetic-cash-enabled`|保持 `false`；仅合成现金账本测试开关，不接通真实支付|

关闭通知则不接收，免打扰结束后投递，安全通知也遵守偏好。批量操作逐条独立处理，保留成功结果、列出失败项。商品采用预约下单 → 卖方线下交付 → 买方确认收货，不需要支付商户或支付密钥，平台不收款、不执行商品退款。

## 微信与真机

|配置项|填写说明|
|---|---|
|`campus.wechat.enabled`|本机默认 `false`；启用前应用 V008 并准备主体权限、实际 AppID 和 AppSecret|
|`campus.wechat.app-id`|只在后端私有配置填写，与开发者工具的本机配置对应|
|`campus.wechat.app-secret`|只由后端读取，不放进小程序、文档或 Git|

关闭微信换码不影响校园Π账号密码登录；已实现的绑定流程要求先用已有账号密码登录，再主动绑定微信，不自动创建新账号。

开发者工具的 `devtoolsApiBaseUrl` 可用 `http://127.0.0.1:8080`；手机使用 `apiBaseUrl`，不能填电脑的回环地址。真机/发布需配置可访问的 HTTPS 地址、有效证书和微信 request 合法域名；后端还需有可接收代理或外部请求的监听设置，`campus.files.public-base-url` 同步为 HTTPS origin。只换成局域网 IP 不能完成整套部署。真实换码、完整真机流程和正式环境目前仍待验收。

默认 `application.yml` 支持 `DB_HOST`、`DB_PORT`、`DB_NAME`、`DB_USER`、`DB_PASSWORD`、`AUTH_IDEMPOTENCY_SECRET`、`WECHAT_LOGIN_ENABLED`、`WECHAT_APP_ID`、`WECHAT_APP_SECRET`、`NOTIFICATION_WORKER_ENABLED` 和 `ADMIN_BATCH_WORKER_ENABLED` 等变量。但私有 YAML 如果已给同一字段写了固定值，就应直接修改该文件，或使用 Spring 对应属性的环境变量（例如 `SPRING_DATASOURCE_PASSWORD`），不能认为上述自定义变量必然覆盖固定配置。最终以进程实际加载的配置为准。
