# 后端基础工程

Spring Boot 3.5.16、Java 17、Maven。mvn spring-boot:run启动，mvn test运行最小启动及404协议测试。当前无业务路由、无登录及鉴权、无数据库或外部渠道连接。

112项业务契约见../docs/api，按A—I唯一分工逐项实现。Spring Boot默认错误入口统一输出业务规范要求的错误包装，不包含内部异常或栈。后续A统一接入会话鉴权及职责权限，G协调数据源和迁移；不能把此工程直接视为业务服务已完成。

不要将已有存储过程再包装在外层未提交事务中；数据和事务规则见../database/README.md及模块任务书。
