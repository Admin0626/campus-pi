# 微信登录与主动绑定接口补充

2026-10-22。负责人确认：先用已有账号密码登录，再主动绑定微信。首次微信登录不创建账号，不按头像、昵称、手机号或客户端提交的 openid 自动匹配账号。

本扩展由 A 模块负责前后端，编号 WX001–WX004。原有112个API编号、九人分工及Bearer契约保持有效；机器可读定义见[微信扩展OpenAPI](wechat-openapi.json)。本补充与原接口文档搭配使用，不表示外部微信服务已完成真实联调。

所有路径以 `/api/v1` 为前缀，均返回原有 `code/message/data/request_id` 信封及 `Cache-Control: no-store`。

|编号|方法与路径|身份|用途及成功data|
|---|---|---|---|
|WX001|GET `/auth/wechat/config`|公开|仅返回 `{ "available": true/false }`，不暴露AppID或密钥|
|WX002|POST `/auth/wechat/login`|公开|已绑定微信登录，返回与API002相同的 `access_token/token_type/expires_in/user`|
|WX003|GET `/me/wechat`|Bearer|可用时返回 `available/bound`，已绑定另有UTC `bound_at`；未启用时只返回 `available:false`，不推断绑定状态|
|WX004|POST `/me/wechat`|Bearer|绑定当前登录用户，成功返回 `{ "bound": true }`|

两个POST仅接受 `{ "code": "由本次wx.login获得的临时凭证" }`。code为1–256位字母、数字、下划线或连字符。禁止提交 `user_id/openid/appid/session_key` 等字段；未知字段400。绑定操作者来自Bearer，微信身份来自后端与微信的换码结果。

## 绑定和会话

1. 使用既有账号密码登录，进入“个人 → 微信账号绑定”，明确点击绑定。
2. 小程序先检查WX001，再调用 `wx.login`，把新code发到WX004。AppSecret只由服务端读取。
3. 服务端验证换码结果，事务内重新检查当前会话、账号状态和绑定唯一性。换码期间退出、过期或停用均不能写入绑定。
4. 同一AppID下，一个微信只能绑定一个校园账号，一个校园账号只能绑定一个微信。重复确认相同关系、使用新的有效code时返回成功；不同关系409。数据库唯一索引裁决并发，失败事务不覆盖成功结果。
5. 登录页点击微信入口，只能登录已绑定账号。未绑定返回403 `WECHAT_NOT_BOUND`，提示先账号密码登录后绑定；不会注册用户。
6. 密码登录与微信登录共用32字节随机不透明令牌、数据库SHA-256摘要、绝对2小时/闲置30分钟、停用和改密撤销机制。小程序仅内存保存令牌，冷启动后重新登录。

每次点击或重试均重新调用 `wx.login`，不能缓存或复用code。绑定响应丢失后先调用WX003确认状态。未新增解绑、替换绑定、手机号授权或微信资料自动同步接口。绑定期间切换校园账号，客户端会停止提交，并要求重新打开绑定页。

## 错误

|HTTP／业务码|含义|
|---|---|
|400 `VALIDATION_ERROR`|请求字段、code格式错误|
|400 `WECHAT_CODE_INVALID`|微信返回凭证无效或已使用，需获取新code|
|401 `UNAUTHENTICATED`|绑定或查询缺少有效会话，或换码期间会话失效|
|403 `WECHAT_NOT_BOUND`|此微信尚未主动绑定校园账号|
|403 `ACCOUNT_DISABLED`|校园账号已停用，不能签发微信登录会话|
|409 `WECHAT_BINDING_CONFLICT`|绑定已被占用，或试图替换已有绑定|
|429 `RATE_LIMITED`|按服务端直连来源地址限制换码请求，60秒窗口最多30次；响应含Retry-After|
|501 `FEATURE_NOT_ENABLED`|服务端未启用，或缺少有效AppID/AppSecret|
|503 `DEPENDENCY_UNAVAILABLE`|微信网络、凭据配置或响应异常；不向客户端回传微信原始错误及密钥|

公开能力查询不会调用微信，不消耗换码额度。绑定必须先通过身份检查；网络调用完成后事务再次检查身份。换码固定访问 `https://api.weixin.qq.com/sns/jscode2session`，不跟随重定向、不支持任意地址配置。服务端不存储或返回微信session_key；本地日志不得启用HTTP请求URL的详细转储。

## 配置与迁移

- 先登记并执行增量迁移 `database/migrations/V008__a_wechat_bindings.sql`，不重建用户表，不使用初始种子覆盖已有库。本轮只在33320端口的独立本地开发库执行，共享环境编号仍由G登记。
- 后端读取环境变量 `WECHAT_LOGIN_ENABLED`、`WECHAT_APP_ID`、`WECHAT_APP_SECRET`，默认false与空值。真实值只放被忽略的服务端本机配置或部署环境；不要填写到共享模板、小程序或聊天中。
- 后端AppID必须对应开发者工具当前小程序，AppSecret必须由项目管理员在本机安全配置。现有AppID仍保留在被忽略的小程序配置中。
- 真机仍须确认HTTPS地址、request合法域名和开发权限。本机127.0.0.1只供开发者工具使用。
