## 实施顺序

1. 实现会话、权限、文件、幂等和编号，补充版本化数据变更。
2. 完成注册登录、资料和认证，先跑越权及隐私用例。
3. 完成商品、帖子、任务主流程，明确12个事务的服务层或存储过程实现方式。
4. 完成消息、站内通知及基础管理统计；实现可靠投递和崩溃恢复。
5. 逐接口执行正常、异常、并发、重试、限流和对象权限验收。
6. 选定支付与通知供应商后补P1适配契约、回调验签、退款模型和沙箱验收。
