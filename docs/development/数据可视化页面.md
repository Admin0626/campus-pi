# 数据可视化页面与JSON模拟数据

日期：2026-10-21。页面归属D模块的管理统计与公共页面接入。本次按用户要求制作**前端模拟页面**，未实现真实统计后端。

## 访问和范围

启动项目后访问 `/admin/modules/analytics`，或管理员登录后点击侧栏“数据分析”。页面沿用原Word图5-36的四个指标卡片、用户增长双折线、交易类型饼图、月度交易柱状图与内容分类环形图。原图见 [analytics.png](../../frontend/public/word-reference/analytics.png)，来源哈希见 [Word资产清单](../verification/word-reference-manifest.json)。

已提供：本周/本月/本季度指标及分类切换；周/月/年趋势；悬停、点击与键盘查看图表；隐藏/恢复趋势序列；明细查看；CSV导出；加载、空数据、格式错误、重试与窄屏布局。页面和CSV均明确标注模拟数据。CSV导出所选统计区间的指标、逐日数据、交易与内容分类明细，含UTF-8 BOM，便于Excel打开。

页面复用现有管理员登录入口。当前可视化数据是公开静态合成文件，不包含真实账号信息；没有新增统计HTTP接口、数据库查询或数据迁移。

## 修改数据

直接编辑 [frontend/public/mock/analytics.json](../../frontend/public/mock/analytics.json)。Vite开发模式下保存后点击页面“刷新”；8080使用打包产物，编辑后需重新构建前端并打包/重启服务。

|字段|含义|
|---|---|
|`schemaVersion` / `source`|当前版本1、固定标记MOCK|
|`asOf` / `timeZone`|模拟数据的固定截止日期2026-10-21，Asia/Shanghai；不会冒充实时数据|
|`openingUsers`|首个记录日期以前的累计用户数|
|`daily`|2025-11-01至2026-10-21的355条逐日记录，连续、按日期排序|
|`daily[].newUsers` / `activeUsers`|当日新增、当日活跃人数|
|`daily[].tradeAmountFen`|按交易类型记录的金额，人民币整数分|
|`daily[].contentCounts`|按内容分类记录的发布数量|
|`tradeCategories` / `contentCategories`|分类ID、显示名及图表颜色，与逐日记录键对应|
|`periods`|本周、本月、本季度的统计日期、同期日期与区间去重活跃人数|
|`monthlyActiveUsers`|逐月去重活跃人数；用作年视图，不能以每天活跃人数相加代替|

所有数据均为固定合成值。当前模拟统计口径只用于演示，不视为团队真实业务统计规则已确定。

## 展示口径

|位置|当前模拟展示方式|
|---|---|
|总用户数|期初人数加截至选定区间末的逐日新增；三个区间末日相同，所以累计人数相同|
|活跃用户|JSON明确给出的区间去重人数，不把DAU求和当作WAU/MAU|
|交易总额|所选区间的全部交易分类金额合计；金额以整数分计算，展示为人民币元|
|内容总量|所选区间发布数量，和内容环形图分类合计一致|
|增长幅度|与上周/上月/上季度同期比较；页面明确列出同期日期；基数为零时不显示虚构百分比|
|用户趋势周/月/年|独立切换近7天、近30天、近12个月；年视图使用月去重人数|
|月度交易趋势|独立显示近6个自然月，末月标明截至日期，避免与完整月份混淆|

2026-10-21位于第四季度第一个月，因此本月与本季度当前日期范围相同，指标值相同是正常的；比较基准分别使用上月同期和上季度同期。
