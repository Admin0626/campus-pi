# 本地开发指南

> 2026年10月24日：首次安装请使用[本地部署说明](../deployment/本地部署说明.md)。下文保留早期工程骨架阶段记录，含“未连接数据库、业务待实现”等过时描述，不能作为当前部署步骤。当前核心业务已经连接MySQL；新文档包含完整40表初始化、私有配置及Web和小程序启动方式。

## 环境

后端使用JDK 17及Maven 3.6.3以上。分别执行java -version、mvn -version，二者都应使用JDK 17；Windows可能有旧Java排在PATH前面，要同时设置当前终端JAVA_HOME和PATH，不修改其他项目的配置。

本机JDK 17位于`D:\Java\jdk-17.0.12`。PowerShell中可为当前终端设置以下变量，然后再次核对版本；其他成员将路径替换为自己的JDK 17安装目录。这不会更改系统或其他终端的Java设置。

```powershell
$env:JAVA_HOME = 'D:\Java\jdk-17.0.12'
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
java -version
mvn -version
```

前端使用Node.js 22.12以上及npm，团队可统一Node 24 LTS。第一次执行npm ci；后续依赖变更需共同提交package.json和package-lock.json。Vue 3通过Vite构建。

Python 3.10以上用于scripts/check_baseline.py；只有运行独立数据库测试才需要安装scripts/requirements-auth-local.txt和本机MySQL客户端。

版本依据：Spring Boot官方3.5系统要求 https://docs.spring.io/spring-boot/3.5/system-requirements.html ；Vue官方快速开始 https://vuejs.org/guide/quick-start.html 。固定版本在backend/pom.xml及frontend/package.json中，不能各人独立升级。

## 启动与配置

后端：在backend执行mvn spring-boot:run，默认8080端口。可通过SERVER_PORT改端口。当前不连接数据库；仅提供Spring Boot基础启动与统一404错误响应，业务API仍待实现。

前端：在frontend执行npm ci和npm run dev，默认5173端口。Vite开发代理将/api发到http://127.0.0.1:8080。如需变更目标，将frontend/.env.example复制为frontend/.env.local并修改CAMPUS_API_TARGET。重启开发服务生效。

根目录.env.example只是配置项说明，Spring Boot不会自动加载根目录.env；当前最小应用没有启用DB_*字段对应的数据源。A/G在接入数据层时补充确定的配置和迁移方式，不得启动自动建表、充值或播种。

不要把服务器密钥放入VITE_*前端变量。基线不含用户或管理员登录实现，公共鉴权、对象权限和文件元数据由对应模块开发。

## 模块接入

前端业务代码放src/modules/<业务名>，公共组件放src/shared，布局放src/layouts。A提供请求与登录状态接入，D提供布局与路由入口。当前只有开发起始页，没有已完成业务页面。

后端在com.campuspi下按account、verification、product、post、task、reward、order、chat、notification等业务包扩展，common仅放统一协议、异常与鉴权基础。不要为九人各建一套应用或重复启动入口。

MySQL持久层框架、会话存储、文件存储、集成测试数据库、支付和外部渠道选型尚待确认。未确定前不引入相互冲突的依赖。公共协议沿用docs/api，任何新增或变更先协调文档及受影响模块。

## 检查与证据

根目录运行python scripts/check_baseline.py；backend运行mvn test和mvn package；frontend运行npm run build。基线检查只核对文档与静态契约；启动测试只验证基础工程。112项业务API、真实登录、任务结算链路、支付和部署另行实现并验证。
