## 事务、权限与文件生命周期

- 同一事务内锁用户/申请、绑定本人VERIFICATION文件、更新认证状态、写审计并保存幂等结果。更换校区或学号时立即暂停旧校园资格；通过后登记校区学号唯一关系；并发冲突回滚。
- 认证名单由服务端配置，未配置返回503，不自动采用报告示例校区。校园认证不会覆盖已核验实名；姓名一致性等未定义规则未自行增加。
- 文件先在私有隔离目录解析真实内容并完成实际安全扫描，再入库及绑定。MIME不依赖客户端文件名或声明。头像上限2MiB，其他图片5MiB，指定证据用途PDF10MiB；图片解码最多1600万像素为资源保护限制。HTML/SVG、加密或含脚本/启动动作/嵌入文件的PDF被拒绝。
- 当前实际扫描适配器为Windows Defender命令行，禁用自动修复以保留证据原字节；未配置、超时或非零退出均拒绝，不返回假CLEAN。当前未实现Linux扫描器；Linux部署须补真实适配器和验证，不能将供应商随意改名绕过扫描。
- 私有根目录不在静态目录；使用随机UUID及服务端路径，拒绝符号链接；不公开原始名称或物理路径。未绑定文件24小时过期，定时清理；已绑定证据保留。此处没有擅自增加长期证据删除政策。
- API014重新核对实际业务关系，返回60秒短时授权。私密授权绑定会话摘要，退出、停用或角色撤销后失效；二进制读取也重新鉴权。商品下架后，原公开链接不再可匿名读取。业务幂等只缓存稳定数据，商品响应在事务后签发新的短时地址。
- 认证材料只允许申请人或认证职责管理员；任务凭证限当前双方或管理员；售后限订单双方或ORDERS职责；私信限双方，REPORTS职责也只能读取合法关联举报案件的图片。敏感管理预览授权和读取均审计，不能借文件接口遍历聊天。

## 配置与启动

共享配置默认留空，敏感职责默认拒绝。Spring Boot不自动加载根目录`.env`；设置进程环境变量或外部YAML。

|属性|配置内容|
|---|---|
|`campus.admin.duties-json` / `ADMIN_DUTIES_JSON`|用户ID到职责数组的JSON；本批使用AUDIT、ROLES、VERIFICATION_REVIEW、ORDERS、REPORTS|
|`campus.verification.allowed-campuses-json`|正式校区名称JSON数组，未确认时留空|
|`campus.files.root`|私有文件绝对根目录，部署者提供并限制系统账户权限|
|`campus.files.public-base-url`|经部署者确认的HTTPS源地址；仅本机允许loopback HTTP；不从请求Host构造|
|`campus.files.scanner-provider`|当前仅支持DEFENDER|
|`campus.files.scanner-executable`|实际安装的MpCmdRun.exe绝对路径，服务端控制|
|`campus.files.cleanup-interval-ms`|默认60000；本机验收显式设为2000用于清理测试|

本机独立库准备（先按账号指南准备V001；不要对共享库运行）：

```powershell
python scripts/local_admin_security.py --configure-local-testing
java -jar backend/target/campus-pi-server-0.0.1-SNAPSHOT.jar --spring.config.additional-location=file:D:/demo_series/campus-pi/.local/auth-dev/,file:D:/demo_series/campus-pi/.local/admin-security/
```

本机工具另外生成被忽略的`.local/admin-security/application-local.yml`，仅授权本机随机密码的local_admin，并使用明确的“测试校区”。它不覆盖原账号配置，也不是正式职责或校区配置。Windows Defender路径随本机实际安装探测，生产环境不得照搬。

开发期Vite同时代理`/api`和`/file-content`；打包后由8080同源提供页面。前端仅从自身源读取严格匹配的文件传输路径，不对任意外部地址发请求；关闭弹窗/切页后撤销Blob对象URL。
