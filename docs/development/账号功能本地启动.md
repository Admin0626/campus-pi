# 账号功能本地启动与检查

本轮以用户分支 `wlky` 上的 `effa518` 为起点，保留 Spring Boot + Vue、Java 17。独立原型保存在原 outputs 目录；仓库中的页面已接入真实 HTTP 与 MySQL。

## 当前访问入口

前后端一起打包后由 Spring Boot 提供：

- `http://127.0.0.1:8080/login`：登录。
- `http://127.0.0.1:8080/register`：注册，成功后回到登录。
- `http://127.0.0.1:8080/admin/login`：原Word图5-23的后台登录。
- `http://127.0.0.1:8080/admin`：管理工作台，登录管理员后可访问。
- `http://127.0.0.1:8080/admin/users`：真实用户列表、详情、启用停用。
- `http://127.0.0.1:8080/home`：用户入口，其余业务显示开发中。

页面能直接打开和刷新。未登录访问管理页会去独立的 `/admin/login`，普通用户不能取得管理 API 数据。令牌当前只在标签页内存中保存，刷新后重新登录，暂未引入长期“记住我”。

## 独立本地数据库

`scripts/local_auth_db.py` 会在 `.local/auth-dev/mysql-data` 创建独立 MySQL 数据目录，监听 **127.0.0.1:33320**；校验数据目录后才进行初始化。它不会连接或更改原 MySQL80 服务，也不使用原微信文档修订测试库。

首次运行需安装 `pymysql` 和 `argon2-cffi`，可装在独立 Python 环境，或本仓库被忽略的 `.local/pydeps`：

```powershell
python -m pip install --target .local/pydeps -r scripts/requirements-auth-local.txt
python scripts/local_auth_db.py
```

默认使用本机 `C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqld.exe`，其他路径设置 `CAMPUS_MYSQLD`。

脚本只对自己创建的空库安装原25表与 A 迁移，并离线初始化 `local_admin`。其密码随机生成，保存在被忽略的 `.local/auth-dev/管理员登录.txt`；不在 README、日志或 Git 中存放固定密码。不要把这个开发库作为生产库。

运行配置写入 `.local/auth-dev/application-local.yml`。Maven 明确排除源码目录下的 `application-local.*`，避免本地密码被打包进 JAR。不要提交 `.local` 或复制私有配置进入资源目录。

2026-10-22按负责人要求调整了当前本机管理员的登录名和密码，具体值仅在被忽略的配置与“管理员登录.txt”中保存；保留原用户ID、职责和历史数据，变更时撤销原会话。私有运行配置可指定`campus.auth.local-short-password-admin-id`，仅允许该ID且当前角色为ADMIN的既有账号使用6位起的登录密码，默认0不启用。前端登录及“当前密码”只检查非空和64位上限，由服务端匹配实际账号策略；注册、其他账号的服务端策略和设置新密码仍要求12–64位，没有写入共享默认账号或固定密码。

## 构建与运行

在两个独立步骤中先构建 Vue，再打包 Java；Maven 将 `frontend/dist` 复制为 JAR 静态资源。

```powershell
$env:JAVA_HOME='D:\Java\jdk-17.0.12'
$env:PATH="$env:JAVA_HOME\bin;$env:PATH"
npm.cmd --prefix frontend ci
npm.cmd --prefix frontend run build
mvn.cmd -B -f backend/pom.xml clean verify
& "$env:JAVA_HOME\bin\java.exe" -jar backend/target/campus-pi-server-0.0.1-SNAPSHOT.jar --spring.config.additional-location=file:D:/demo_series/campus-pi/.local/auth-dev/
```

JDK 路径与最后的外部配置路径按实际机器调整。共享环境不运行独立数据库初始化脚本；由 G 审核并登记 `V001__a_account_sessions.sql` 的编号和顺序，再显式执行迁移。

如果只开发 Web，可启动原来的 `frontend npm run dev`，由 Vite 的 `/api` 代理转发到后端。小程序目录是 `miniprogram/`，独立配置要求见其 README；Web 手机排版测试不能代替微信真机验收。

## 当前检查

```powershell
python scripts/check_baseline.py
python scripts/check_auth_http.py
node scripts/check_auth_browser.cjs
node scripts/check_miniprogram_adapter.cjs
python scripts/check_wechat_compile.py
node scripts/check_page_entries.cjs
```

HTTP 检查严格核对独立测试库目录与端口，会创建合成账号，并使用只影响专用测试账号的临时触发器验证注册事务回滚；结束时删除本次触发器。浏览器检查需要 Playwright 和 Chrome，本机通过 `PLAYWRIGHT_MODULE` 指向 Codex 自带 Playwright；其他环境可在独立验证环境安装。

验证结果位于 `.local/auth-dev/http-acceptance.json`、`browser/browser-acceptance.json`、`miniprogram-adapter.json`。它们不含凭证。`docs/verification/账号功能验证记录.md` 保存可提交的验证摘要。
