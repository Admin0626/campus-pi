# 管理通知发布与持久投递

2026-10-21：API103–110八项管理操作已实现，并补齐API065–071作为实际收件和偏好依赖。管理范围累计40/41项接入；真实退款API099及报告超出契约的功能仍保留在总清单，不称整个目标完成。

## 已实现的功能

|范围|实现及边界|
|---|---|
|草稿与查询 API103–106|列表/状态/分页、创建、详情和全量替换；仅草稿可编辑，正文纯文本，目标严格按全体/校区/指定用户验证；创建幂等并审计|
|审核发布 API107|显式NOTIFICATION_PUBLISH职责；人工核对内容及对象后固定接收者集合，排除关闭接收者；快照、attempt、发件箱、job、状态、审计及幂等同事务|
|撤回 API108|取消未执行投递和发布作业，收件箱立即隐藏；保留旧尝试，不能伪称追回已发送的外部消息|
|投递记录 API109|敏感职责及读取审计；状态/渠道筛选，尝试ID倒序；不输出逐人阅读明细或供应商原始信息|
|单次重试 API110|仅最新失败记录、最多5次；不覆盖旧尝试，事务内新增待投递项；关闭或已删除拒绝，免打扰时延期；外部未接入501|
|本人通知 API065–069|仅本人、未删除、未撤回且站内尝试成功的记录；列表筛选分页、详情、独立read/click/delete；GET不隐式改状态，重复首次时间保持，删除不影响他人|
|本人偏好 API070–071|无记录默认视图；完整替换、布尔开关、HH:mm:ss成对校验，跨夜可用，起止相等拒绝；短信邮件开关true返回501且不部分写入|

全体/校区范围按当前用户记录选取，不擅自新增账号状态或角色过滤；指定用户须存在。发布后的注册、启用偏好或校区变化不扩大既定目标。实际站内成功不改变已读或点击。历史通知不会因关闭新通知而自动删除。

## 负责人确认的规则

负责人已明确：关闭则不接收；免打扰结束后投递；安全通知也遵守偏好。覆盖初版旧规则，见[接口规则修订](../api/通知规则修订记录.md)。免打扰使用Asia/Shanghai，运行与数据库时间为UTC。

预建的notification_receipts只固定快照，尚未投递时不在API065/066中出现。worker真正成功提交后才可见，并设置实际received_at；已发布状态表示快照完整，不能代替逐人成功/失败记录。投递前再次锁偏好核对；排队时关闭会取消，变更免打扰按最新时段重算。偏好版本使变更后的待执行项及时被重新检查，不需等待旧截止时间；重开不自动复活取消项。

V004保存发布job与发件箱，V005追加available_at及偏好版本，不重写已应用迁移。worker用通知和工作行锁在事务中完成动作，进程停止回滚未提交处理，下个实例可恢复，无内存队列依赖。投递失败保留安全失败原因；持久记录失败时保留待执行，下轮恢复。异常快照不标已发送，并从可执行批次排除，避免阻塞健康工作。

## 页面

管理页沿用原Word的深色侧栏、通知列表/发送记录两页签和表格。发布前显示真实标题、正文、目标及确认勾选；拒绝未审核直接点击成功。无契约的关键词/日期筛选、图文、删除和定时发布不伪造接口，仍列作范围差异。

Web辅助收件页位于/modules/I，由原个人页“通知中心”进入，参照原图5-19的页头、类型页签和通知卡片；详情明确提供read/click/delete，偏好独立弹窗。新增交互不宣称原图逐像素一致，也不作为微信原生小程序收件页面已完成的证据。

## 启动与复现

先由G登记并执行V001–V005。scripts/local_admin_notifications.py仅允许33320端口、campus_pi_auth_local和匹配目录的本任务独立库；若发现部分迁移即停止，不能用初始DDL覆盖库。恢复旧版本时停worker并保留表、文件、attempt和审计。

共享默认NOTIFICATION_WORKER_ENABLED=false；迁移到位后显式设true，轮询间隔默认2000ms。本机验收进程显式true，现金始终false。真实服务须显式配置NOTIFICATION_PUBLISH职责；仅ADMIN角色不够。正式人员授权为空，本机local_admin合成授权不代表部署配置。

复现：worker显式false启动服务，运行scripts/check_notification_publication_http.py --phase prepare；重启同一真实服务并设worker true，再运行--phase resume；最后运行scripts/check_notification_publication_browser.cjs。旧故障组另运行check_admin_notifications_http.py的相同两阶段及其browser脚本。两组都核对真实进程模式及独立库，不可直接指向共享环境。

当前尚未接短信邮件、移动主动推送、正式职责/部署或微信原生收件页面。API099退款依赖真实供应商、原状态与退款预占模型，仍501，不伪造退款成功。
