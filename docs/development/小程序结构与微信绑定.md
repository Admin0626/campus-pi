## 已确认的微信规则

负责人选择“先用已有账号密码登录，再主动绑定微信”。登录页微信按钮用于已绑定用户；首次使用需先密码登录，进入个人页主动绑定。绑定关系不允许被其他账号抢占，也不直接替换。首次未绑定返回提示，不产生账号。未新增手机号授权、解绑或账号合并。

接口说明及配置步骤见[微信接口补充](../api/微信登录与主动绑定接口补充.md)。默认不开启外部微信换码，缺少服务端私有配置时页面会说明原因。真实AppID/AppSecret不会进入共享文件。

## 验收入口

1. 开发者工具重新编译当前`miniprogram`目录。
2. 用普通校园账号密码登录，核对首页、发现、发布、私信、个人切换和安全区；后三个入口明确显示开发中。
3. “个人 → 微信账号绑定”：服务端未配置时显示尚未配置；配置真实服务后，明确点击绑定。
4. 退出后用同一微信登录，核对仍为原校园账号；未绑定微信应提示先密码登录再绑定。
5. 核对注册返回账号回填、密码清除，以及过期、断网、停用与绑定冲突提示。
